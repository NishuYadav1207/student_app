Frequently Asked

Find answers to common questions about Student Core.

What is Student Core?

Student Core is a student management system for managing student personal and academic records.

Can I add new students?

Yes. After logging in, use the Add Student option from the dashboard sidebar.

Can student information be edited?

Yes. Every student record can be viewed and edited from the student management section.

Can a student record be deleted?

Yes. The system provides a separate confirmation page before permanently deleting a record.
